# 🛠️ Developer & Document Automation Utilities

**Author:** Mehmet Efe Özhan

---

## 📌 Included Utilities

1. **`pdf_to_md.py`:** Converts complex PDF documents to clean GitHub-Flavored Markdown using Microsoft's MarkItDown engine, with direct Windows clipboard integration (`ctypes` Win32 API) and Tkinter file picker.
2. **`PDF_splitter.py`:** Interactive GUI and CLI tool to extract, reorder, and split page ranges from large documents (`pypdf`).
3. **`pdf_combiner.py`:** Batch utility to merge multiple engineering lecture notes and reports into a single formatted PDF.
4. **`convert_to_markdown.bat`:** One-click Windows batch launcher for instant document conversion.
