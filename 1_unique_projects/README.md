# 💡 Category 1: Unique Projects

This directory contains software engineering, autonomous AI agent frameworks, hardware-accelerated deep learning pipelines, and financial microstructure data infrastructure.

---

## 📂 Projects

### 1. [`fusion360-mcp-framework/`](./fusion360-mcp-framework)
- **Domain:** Autonomous CAD Modeling & Verification via Model Context Protocol (MCP).
- **Core Features:** 5-stage quality-gated execution loop (`QUERY` -> `PLAN` -> `EXECUTE` -> `VERIFY` -> `RECOVER`), unit interceptor hooks (mm/in to cm/rad), programmatic B-Rep inspection, and parametric Geneva mechanism integration test.

### 2. [`vocal-remover-pro/`](./vocal-remover-pro)
- **Domain:** Neural Audio Stem Separation with Hardware Acceleration.
- **Core Features:** 3-stage neural pipeline (MDX-Net for vocal isolation + UVR-DeEcho + UVR-DeNoise), AMD/Intel GPU acceleration via `onnxruntime-directml`, and dual CLI/Streamlit interfaces.

### 3. [`orderbook-microstructure/`](./orderbook-microstructure)
- **Domain:** High-Throughput Market Microstructure Ingestion & Visualization.
- **Core Features:** Real-time Level 2 crypto order book streaming via Cryptofeed into columnar DuckDB, Polars dataframe transformation, and interactive Streamlit depth curves and spread heatmaps.

### 4. [`web-platform-odtusat/`](./web-platform-odtusat)
- **Domain:** Static Web Infrastructure & Automation.
- **Core Features:** Hugo static site platform for METU Underwater Society (`odtusat.org`), bilingual taxonomy (TR/EN), and Python scripts for membership roster sorting and data validation.

### 5. [`developer-utilities/`](./developer-utilities)
- **Domain:** Engineering Workflow & Document Productivity Tooling.
- **Core Features:** Native Windows MarkItDown clipboard bridge (`pdf_to_md.py`) using Win32 API, interactive PDF splitters, and automated report binders.
