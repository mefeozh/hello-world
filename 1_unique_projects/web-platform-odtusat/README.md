**Author:** Mehmet Efe Özhan  
**Framework:** Hugo Static Site Generator | Python Data Tools

## 📌 Overview

Official bilingual web platform and membership management infrastructure for the **Middle East Technical University Underwater Society (ODTÜ-SAT)** (`odtusat.org`).

- **Static Site Engine:** Fast Hugo SSG with custom layouts and CSS assets.
- **Bilingual Content:** Seamless Turkish and English taxonomy routing.
- **Roster Utilities:** Python automation scripts (`parse_members.py`, `sort_members.py`) for member directory validation.
